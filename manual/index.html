1. Purpose & Quality Gate Philosophy

This Standard Operating Procedure (SOP) governs the operation, inspection, quality verification, and maintenance of the Industrial Conveyor Belt BOM Vision Inspector installed on Packaging Line 1 at the Khalapur Knock-Down (KD) Furniture Facility.

Mandatory 100% Match QC Gate Rule: Under zero circumstances may a packaging kit carton be closed or a QC shipping barcode label printed if any hardware item has a count discrepancy ($\text{Counted} \neq \text{Target}$). If any item is missing or over-counted, the system automatically engages the physical conveyor interlock and blocks label generation.

1.1 Scope

Applies to all hardware packing kits (`HRD PKT`) containing fasteners, plugs, dowels, brackets, and hinges. The vision station verifies individual components tumbled across the conveyor belt prior to boxing.

2. Station Architecture & Layout

The inspection cell consists of the following tightly integrated physical and logical components:

Component Specification Industrial Function
Overhead Camera 1280x720 / 1920x1080 @ 30-60 FPS Industrial USB3 / RTSP Captures clear, orthogonal top-down frames of hardware fasteners moving on the conveyor belt.
Conveyor Belt Matte Black / Dark Green Anti-Static Belt (0.2 - 0.4 m/s) Provides high-contrast background for fastener oriented bounding box (OBB) contour segmentation.
Virtual Tripwire Mathematical 2D line segment ($P_1 \to P_2$) with normal vector check Increments the counted quantity of a tracked fastener only when its centroid crosses the line in the downstream direction.
Vision Engine Ultralytics YOLO26-OBB (nms=False) + ByteTrack Performs high-speed edge inference with oriented rotation angles ($\theta$) and persistent track IDs.
Barcode Scanner Zebra DS2208 Handheld 2D/1D Scanner (USB Virtual COM) Instantly loads active BOM recipe when operator scans the Master Item Code traveler.
QC Label Printer Zebra ZD421 Industrial Direct Thermal (203 DPI) Prints authorized QC barcode pass label upon 100% verification match.
PLC / Relay Interlock Modbus TCP / Opto-isolated 24V Relay Stops conveyor drive or triggers pneumatic reject gate if batch fails verification.

2.1 Live USB Camera Setup & Device Index Selection

The vision station supports plug-and-play USB cameras and industrial UVC devices with dynamic runtime index switching:

Step 1

Connect USB Hardware

Plug the industrial camera into a USB 3.0 / USB 3.1 port on the workstation.

Step 2

Choose Camera Index

In the Home / Inspection ribbon, select USB Camera [Index 0], [Index 1], etc., or click the camera pill in the top title bar.

Step 3

Rescan & Configure

Open Camera Setup to re-probe USB ports or configure resolution (1280x720 HD recommended).

Step 4

Inspect Live Feed

The live camera feed streams instantly with real-time YOLO26-OBB bounding boxes and tripwire tracking.

3. Zero-Touch Startup Procedure

Step 1

Power Inspection Cell

Ensure overhead industrial LED illumination is ON and conveyor main drive is energized.

Step 2

Execute Launcher

On Windows 11 desktop, double-click start_windows.bat. No terminal commands required.

Step 3

Automatic Self-Check

The launcher activates .venv, verifies database tables, and starts the inspection service.

Step 4

Browser Interface Ready

Chrome automatically opens to http://localhost:8000 with the default recipe pre-loaded.

Ubuntu Linux Production Note: On plant servers, the station runs automatically on system boot via systemd. Verify status with: sudo systemctl status bom-inspector.service.

4. Daily Line Operator SOP (Step-by-Step)

4.1 Shift Routine Flowchart

  1. Scan Production Traveler Barcode: Pick up handheld scanner and scan the Master Item Code on the job sheet (e.g. 31162814SD05076). The title bar updates immediately with the recipe badge.
  2. Start Conveyor Feed: Tumble or place hardware components onto the moving belt upstream of the virtual tripwire line.
  3. Monitor Excel Recipe Grid: Observe the 35% right-hand pane as counts increment in real-time. Follow the color guide below:
Status Badge Row Color Meaning Operator Action Required
PROG Pale Yellow In Progress (Counted > 0 but < Target) Continue feeding remaining parts of this type.
MATCH Pale Green Exact Target Match ($\text{Counted} = \text{Target}$) Target reached. Do not feed additional items of this type.
OVER Pale Red Over-Counted ($\text{Counted} > \text{Target}$) Stop feed. Remove excess item from collection bin. Click "Reset Counts".
EXCL Slate Gray Packaging Excluded (Carton, Box) Handled manually. Excluded from tripwire gate.

4.2 Batch Completion & Label Printing

  1. When all items show MATCH and the top banner turns GREEN ("PASS - 100% BOM MATCH"), click the ribbon button "Complete Batch & Print QC Label".
  2. The Zebra printer dispenses an authorized QC Barcode sticker containing the verification token (e.g. QC-E7A492B1). Apply the sticker to the carton face.
  3. Click "Reset Counts" to prepare the station for the next kit.
Protocol if Batch is BLOCKED (Red Alert Modal):
If the Red Alert Dialog appears, review the exact list of missing drawing numbers. Retrieve the missing items from stock bins, feed them across the tripwire, confirm they turn green, and re-click "Complete Batch".

5.2 Canonical Part Slugging Rule

Fasteners lacking formal drawing numbers (marked as —, -, or NA) are automatically assigned deterministic uppercase slugs prefixed with NO_DWG_. This guarantees persistent class indexing in the YOLO database without manual intervention.

5.3 Packaging Exclusion Rule

Line items containing terms like CARTON, CORRUGATED BOX, or MASTER BAG automatically have their is_vision_inspected flag defaulted to False. They remain visible in the BOM table but do not block the conveyor tripwire verification gate.

6. Component Image Annotation & YOLO26 Training SOP

When introducing a new plant BOM recipe or adding new hardware components to the vision model:

  1. Navigate to the Dataset & Labeling ribbon tab.
  2. Click "Browse Component Image" and select a high-resolution photo of the hardware item from your local computer (or click "Camera Capture" to grab from the live conveyor).
  3. In the right panel, select the Item Name from the plant BOM dropdown (e.g. M4X10 SCREW CHEESE HEAD...). This Item Name acts as the ground-truth YOLO26 class label.
  4. (Optional) Click "Auto Fastener Box" to let OpenCV detect the fastener's contour and oriented bounding box.
  5. Click "Add to Training Folder". The image and normalized YOLO-OBB annotation are stored directly into datasets/bom_dataset/images/train/ and labels/train/.
  6. Repeat this process one by one for each component image until all required BOM line items have training images collected.
  7. Click "Start YOLO26 Model Training". The Ultralytics engine fine-tunes the model, displays live epoch progress and scrolling console logs, and automatically confirms and activates the new model weights upon completion!

7. Model Training & Live Hot-Swapping

The system features an autonomous background training runner utilizing Ultralytics YOLO26-OBB with native end-to-end inference (nms=False).

  1. Select the Model Training ribbon tab.
  2. Choose the base architecture:
    • yolo26n-obb.pt: Nano model. Fastest inference (<10ms), recommended for low-power edge PCs.
    • yolo26s-obb.pt: Small model. Recommended balance of speed and precision for small screw threads.
  3. Set image size to 1280 (critical for small fastener thread pitch resolution).
  4. Click "Start YOLO26-OBB Training".
  5. Monitor real-time training loss and mAP50 convergence on the live dashboard.
  6. Upon completion, click "Activate Model" in the weights table. The running vision thread reloads weights into RAM instantaneously without stopping the conveyor.

8. Virtual Tripwire Calibration SOP

The virtual tripwire must be calibrated perpendicularly to the conveyor belt travel direction:

  1. On the Home / Inspection ribbon, click "Tripwire Adjust". Yellow grab handles appear at coordinates $P_1$ and $P_2$.
  2. Drag $P_1$ to the top edge of the conveyor belt and $P_2$ to the bottom edge.
  3. Ensure the line is positioned downstream of the initial tumbling zone so parts have stabilized before crossing.
  4. Click "Tripwire Adjust" again to lock the coordinates into the persistent database.

9. Maintenance & Troubleshooting Matrix

Fault Condition Probable Root Cause Corrective Action
Over-Count False Triggers Belt reflections, conveyor seam glint, or operator hands passing line. Adjust OpenCV threshold slider; ensure operators keep hands clear of the active tripwire line during feeding.
Missing Screw Detection Fasteners touching or overlapping each other as they cross tripwire. Spread fasteners evenly on the belt during feed; re-train model with more clustered dataset samples.
Camera Status "OFFLINE" USB3 cable loose or RTSP camera network packet loss. Re-seat industrial locking USB3 cable; verify camera power supply; toggle "Camera Source" in ribbon.
Zebra Label Not Printing Batch is BLOCKED due to count mismatch; or printer out of media. Resolve missing items listed in Red Modal; check Zebra printer green LED status and ribbon supply.
Recipe Not Loading on Scan Barcode reader carriage return suffix disabled or invalid code. Scan Zebra configuration barcode "Add Enter Suffix"; confirm Master Code exists in BOM Recipes tab.
